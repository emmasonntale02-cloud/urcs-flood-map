# URCS Community Flood Early Warning Network – Interactive Map

Interactive map of the 27 community river gauges, automatic flood monitoring stations
and community radios installed by the Uganda Red Cross Society across 7 districts.

- `index.html` is the whole site: one self-contained file with no server or build step.
- To update the map, replace `index.html` with a new version and commit.
- Hosting: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
